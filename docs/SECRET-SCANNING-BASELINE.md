CI (`Every baseline entry has a documented reason`, last step of `.github/workflows/gitleaks.yml`) fails when an entry has no row. Adding a row is how a reviewer sees that something is being baselined and why; the PR/range scan never uses the baseline, so a new secret in a pull request still fails.
